Credits#

This is a neobrutalist rewrite of the original site. It is built with hand-written HTML generated from Markdown and Tailwind CSS compiled locally. A small local script powers post search, the collapsible mobile navigation, and the back-to-top control. There is no analytics and no third-party requests.

The original design was built with Hugo and the Blowfish theme by Nuno Coração. The profile photo and favicons come from the original site. The background is a CSS grid rather than an image, so there is nothing extra to download.

Privacy#

This site ships no analytics, no cookies, no trackers, and no ads.

If the site is hosted behind a service like Cloudflare, that provider may log basic request data at the edge. I don't use it, and there is no client-side code here that collects anything.

The only requests to other domains happen when you choose to click an external link. Search runs entirely in your browser; the index is a static file served from this domain.
