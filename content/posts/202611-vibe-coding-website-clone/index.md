I know a lot of people on the indie web are not really fans of AI especially when it comes to our websites.
I myself share quite a lot of those sentiments especially if one treats it like a replacement for actually knowing how to build software.
However, I’ve been thinking a lot lately whether I should cave in and use it for the website code while maintaining full control of my writing.

I mean I already use LLM to assist me with other projects, especially with documentation and fixing issues that are a hassle.
What’s one more step into the deep end?

The reason I’ve been pondering on this recently is that I got to finally try some agents.
I heard all the hype before but never tried any until I gave opencode a shot not too long ago.
I fired up a new project, gave it access to GitHub CLI and gave it some instructions.
The perfect guinea pig proved to be my own site.
I know it very well, its feel and vibe is ingrained in me, and the scope is small enough that I can review everything.
And so I got to work cloning my site while changing the design style to neobrutalism, a design style I’ve considered coding and switching to for some time now.

To make it clear, the result will not replace the current site.
This was merely a private test of popular tool.

So what were the results of my experiment?

I have to say the results were spectacular.
Aside from a few bugs here and there and design choices I didn’t agree with, the code made sense and the result was more than usable.
Heck, I think a lot of people would praise the design.

The question that keeps coming to mind is this: what’s the difference between using pre-built themes for a static site generator and using AI to code your website?
Keep in mind that you’re likely indirectly a beneficiary AI if the creators and contributors of these themes are using it themselves.
Aren’t you more aware of your vibe-coded “slop” if you actually reviewed the output along the way?

I don’t think I’m making sense and I don’t have a fully formed take on this but I felt like writing it up.
What I know is I’m not ready to hand over the reins to AI especially with this website but I can see the various opportunities it can open when used wisely.
